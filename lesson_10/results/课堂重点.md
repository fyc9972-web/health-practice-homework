# 第 10 课课堂重点：Git 与 GitHub

- Git 是本地版本管理工具；GitHub 托管远程仓库。
- 工作区保存实际文件；`git add` 选择本次改动；`git commit` 保存本地版本；`git push` 上传提交。
- `.gitignore` 排除尚未跟踪的缓存和本地配置，不能自动删除已经跟踪的文件或清除历史。
- `git status` 查看当前状态；`git log` 查看提交历史，二者都不会上传文件。
- 按课次提交应使用 `git add -- lesson_2` 等具体路径，先检查暂存内容，再提交。
- `git pull` 获取并整合远程更新；`git clone` 用于首次取得远程仓库。
- 多条本地提交可以统一 push，提交记录会保留实际操作时间。
