## 目录与使用

| 目录 | 内容 |
| --- | --- |
| results/ | 课堂重点、已填写工作单或报告及相关结果附件 |
| [assets/](assets/) | 原有数据、配图或分析资源 |
| [slides/](slides/) | PPT 课件 |
| [notebook/](notebook/) | 原有实验 Notebook |
| [scripts/](scripts/) | 代码与构建脚本 |
| [materials/](materials/) | 原始说明、空白工作单和参考材料 |

运行代码时以本课目录为工作目录，在 VS Code / Jupyter 中选择对应 Python 环境。

保留数据来源、署名和许可；虚拟环境、缓存和本地归档不作为当前课程文件提交。
