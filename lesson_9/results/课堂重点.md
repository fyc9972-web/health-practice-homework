### 0.2 整节课的知识路线

```text
单棵决策树：容易理解，但深树可能过拟合、对训练样本变化敏感
    ↓
集成：组合多个模型；平均可以减小不完全同步的预测波动
    ↓
Bootstrap：通过有放回抽样制造不同训练集
    ↓
Bagging：独立训练多棵树，再聚合预测，主要降低方差
    ↓
随机森林：进一步随机限制每个节点的候选特征，降低树之间的相关性

另一条改进路线：Boosting
    当前模型还有不足 → 下一轮有针对性地修正 → 顺序累加
    ↓
共同落点：同一协议比较表现、稳定性、解释成本，限定结论范围
```

这里的“基学习器”就是组成集成的单个模型，例如森林中的一棵树。“弱学习器”通常指能力有限、但有一定预测信息的模型；在理想的二分类 boosting 讨论中常要求其加权错误率低于随机猜测。**并非所有集成中的单个模型都很弱**，随机森林中的深树可以把训练集拟合得很好。

## 1. 先学会读懂一张机器学习数据表

**【核心重点·必须理解】对应：课件第 3–4 页；工作单“数据与协议”。**

### 1.1 样本、特征、标签和模型是什么

想象一张表：每一行是一条观察记录，每一列是一项记录内容。

| 术语 | 通俗解释 | 本课例子 |
|---|---|---|
| 样本 | 一条要学习或预测的观察记录 | 一条肿块样本记录，或一个 CTG 信号片段 |
| 特征 | 预测时提供给模型的信息 | 细胞核周长、胎心率基线 |
| 标签 | 学习时提供的已知答案 | 恶性=1；病理型=1 |
| 模型 | 从特征到预测结果的计算规则 | 决策树、逻辑回归、随机森林 |
| 训练／拟合 | 用已知特征和标签确定规则 | 决定树的切分特征和阈值 |
| 预测 | 把新记录交给已有规则计算 | 输出类别、概率或排序分数 |
| 超参数 | 训练前设定、控制模型怎样学习的选项 | 树的最大深度、树的数量 |

```text
训练：X（特征表） + y（已知标签） → 学到模型 f
预测：新记录的特征 x → f(x) → 类别、概率或分数
```

公式注释：`X` 是多条记录组成的特征表；`x` 是其中一条记录的特征；`y` 是标签；`f` 是学到的预测规则。模型预测新记录时不能偷看该记录的标签。

**一定分清三种输出：**

- **类别**：最终判成 0 还是 1。
- **概率估计**：例如 0.8，模型估计该记录属于正类的可能性；是否可信还涉及概率校准。
- **分数**：主要用于排序，值越高越倾向正类；不一定在 0–1 之间，也不一定是概率。

例如，本课默认的 `SVC` 使用 `decision_function` 得分计算 AUC，不能把得分 2.3 解读为“概率 230%”。

### 1.2 方案 A：WDBC 乳腺肿块细胞核特征

| 项目 | 本课定义 |
|---|---|
| 数据目录 | `data/` |
| 一行代表 | 一份乳腺肿块细针穿刺样本的图像特征记录；不是一颗细胞一行 |
| 规模 | 569 条记录、30 个连续特征 |
| 正类 | `malignant=1`，恶性 |
| 负类 | `malignant=0`，良性 |
| 训练／验证／测试 | 341／114／114 |
| 不作为特征 | `sample_id`、标签列 |
| 特别注意 | 原始 sklearn 数据编码为 0=恶性、1=良性；课程数据已重编码，不能再按原始含义理解 |

这些特征由细胞核的不同形态量汇总而来，例如 radius（半径）、perimeter（周长）、area（面积）、concave points（凹点）。`mean` 表示均值，`error` 对应标准误，`worst` 在该数据定义中表示三个最大测量值的均值，不是“患者最坏的未来结局”。

课件中 `worst perimeter` 可以先理解为“较大细胞核的周长汇总”，`mean concave points` 可以理解为“细胞核边界凹点特征的平均值”。读树时先看数值与阈值的关系，不需要先学会病理诊断。

**结论边界：**这是对已有样本良恶性标签的分类任务，不能把输出直接当成患者未来患病概率。表中也缺少可用于核验患者独立性的分组信息。

### 1.3 方案 B：CTG 胎心监护信号特征

| 项目 | 本课定义 |
|---|---|
| 数据目录 | `data-ctg/` |
| 一行代表 | 一段胎心监护信号片段的自动分析特征；不是一位孕妇 |
| 规模 | 2,126 个片段，来自 352 个录音文件；21 个连续特征 |
| 正类 | `pathologic=1`，原专家判读 NSP=3，病理型 |
| 负类 | `pathologic=0`，原 NSP=1 正常与 NSP=2 可疑合并 |
| 正类占比 | 176／2,126，约 8.3% |
| 训练／验证／测试 | 1,279／424／423 个片段 |
| 不作为特征 | `sample_id`、`recording_id`、标签列 |
| 分组变量 | `recording_id`：同一录音的所有片段必须留在同一集合和同一折 |

常见特征：`LB` 是胎心率基线；`ASTV` 是短时变异异常的时间百分比；`ALTV` 是长时变异异常的时间百分比；`DP` 是每秒延长减速次数；`Mode`、`Mean` 等是胎心率直方图统计量。完整字段定义见 `data-ctg/README.md`。

**为什么一定要分组？**同一录音切出的片段可能高度相似，甚至时间重叠。如果一部分进入训练，另一部分进入验证，就像考试题与练习题大量重复，分数容易偏高。按录音分组评估的是模型面对未见过录音时的表现。

**结论边界：**录音文件不一定等于孕妇个体；标签是专家对信号的判读，不是胎儿未来结局，也不能据此保证跨医院适用。

### 1.4 为什么 ID 不能随意输入模型

`sample_id` 通常只是追踪编号，不是可迁移的生物医学信息；编号还可能暗含排序或采集过程，让模型学到偶然规律。`recording_id` 在本课用于防止数据泄漏，也不作为预测特征。

标签列更不能放进 `X`。否则模型等于直接拿到了答案，得到的高分没有预测意义。

**本节过关：**你应该能说清“这份数据的一行是什么、正类是什么、哪些列不能输入、哪些记录必须放在一起”。

## 2. 训练、验证、测试与交叉验证

**【核心重点·必须理解】对应：课件第 15 页；工作单“数据与协议”、F。**

### 2.1 三类数据各自做什么

| 集合 | 回答的问题 | 允许做什么 |
|---|---|---|
| 训练集 train | 模型怎样从已有数据学规律？ | 拟合模型及训练所需的预处理 |
| 验证集 validation | 在候选模型和设置中选哪个？ | 比较模型、选择超参数或阈值 |
| 锁定测试集 test | 选定方案对未参与选择的记录表现如何？ | 协议锁定后作最终评价 |

```text
全部数据
├─ 开发集 development
│  ├─ train：学习规则
│  └─ validation：比较候选
└─ 锁定 test：最终评价，不参与选择
```

公式／结构注释：本课“开发集”指 train 与 validation 的合并。WDBC 开发集 455 条，CTG 开发集 1,703 条。测试集从开发过程独立留出。

**为什么不能先看测试标签？**你一旦根据测试成绩改模型、选特征、改阈值，测试集就参与了选择。此时再把该成绩说成独立最终评价，会高估表现。

### 2.2 五折交叉验证怎样做

把开发集分成五份：每轮用四份训练、剩下一份评价，轮换五次。这样每一份都做过一次验证部分。

```text
第 1 轮：验证第 1 折，训练其余 4 折
第 2 轮：验证第 2 折，训练其余 4 折
……
第 5 轮：验证第 5 折，训练其余 4 折
```

结构注释：这里的“五个模型”是同一种方法在五组训练数据上分别拟合，用于评价；与部署时用五棵树投票不是一回事。

- WDBC：使用分层交叉验证，尽量使各折的正负类比例相近。
- CTG：使用 `StratifiedGroupKFold`，先确保录音不跨折，再尽量保持类别比例。分层通常不能保证各折比例完全相等。

结果常写成“均值 ± SD”。均值描述这几折的平均成绩，SD 描述折与折之间的成绩波动。**折间 SD 不是 95% 置信区间，也不是某个病人的预测不确定性。**

### 2.3 什么叫数据泄漏

数据泄漏是评价阶段的信息提前影响了训练或选择，使评价不再公平。常见例子：

1. 把标签或由标签派生的列作为输入。
2. 同一 CTG 录音的片段同时出现在训练和验证。
3. 先对全体数据拟合标准化，再做交叉验证。
4. 用测试集选择树深、特征、阈值或集成权重。

正确做法是：**每一折只用该折训练部分拟合预处理与模型，再对该折验证部分应用这些规则。**

### 2.4 为什么本课同时报告验证集和开发集 CV

固定验证集便于所有方法在相同记录上直接比较；开发集五折 CV 则补充观察模型对划分的敏感性。两者都属于开发阶段的证据，不能称为外部验证。

本课演示脚本使用预设参数。若你看过这些结果后继续反复调参，原 CV 成绩也会受到选择影响；后续若需要严谨评价大规模调参流程，可使用嵌套交叉验证等方案。这属于拓展，本课先把固定协议执行正确。

## 3. 决策树：先理解一棵树怎样学习与预测

**【核心重点·必须理解】对应：课件第 5–6 页；工作单 A。**

### 3.1 决策树就是一连串“是否满足条件”

- **根节点**：第一道问题。
- **内部节点**：继续提问，例如“周长是否小于某个值”。
- **分支**：条件成立或不成立时走的路径。
- **叶节点**：不再分裂的终点，给出预测。
- **阈值**：把特征数值分成两部分的界限。

训练树时，算法决定问什么、阈值多少；预测时，样本按照已经学好的规则走到叶节点。

### 3.2 读懂课件第 5 页的完整例子

```text
worst perimeter ≤ 105.95？
├─ 是：继续问 worst concave points ≤ 0.17？
│  ├─ 是：良性 198，恶性 4
│  └─ 否：良性 0，恶性 3
└─ 否：继续问 mean concave points ≤ 0.05？
   ├─ 是：良性 13，恶性 8
   └─ 否：良性 3，恶性 112
```

工作单样本：`worst perimeter=120`，`mean concave points=0.08`。

1. 120 大于 105.95，走根节点的“否”。
2. 0.08 大于课件显示的 0.05，继续走“否”。
3. 到达“良性 3、恶性 112”的叶节点。

```text
p̂(恶性 | 该叶节点) = 112 ÷ (3 + 112) ≈ 0.974
```

公式注释：`p̂` 读作“估计概率”；分子是落在这个叶节点的恶性训练样本数，分母是该叶节点训练样本总数。按 0.5 阈值分类时预测为恶性。课件把它显示为约 0.97。

这是叶节点中的经验类别比例，**不是说模型证明这位患者有 97.4% 的未来患病风险**。若训练时使用样本权重，叶节点概率相应按加权计数计算。

课件阈值经过四舍五入；实际代码判断边界附近的样本时，应读取模型保存的完整阈值。本题数值远离边界，结论不受影响。

### 3.3 树如何决定问哪个问题：Gini 不纯度

“纯”指节点里的样本几乎都是同一类；“不纯”指不同类别混在一起。Gini 衡量混杂程度，不是预测准确率。

```text
Gini = 1 − (p₀² + p₁²)
二分类时也可写为：Gini = 2p₁(1 − p₁)
```

公式注释：`p₀`、`p₁` 分别是当前节点中负类和正类的比例，二者相加为 1。全部同类时 Gini=0；两类各一半时 Gini=0.5，是二分类的最大值。也可理解为从该节点按类别分布独立抽两次，类别不同的概率。

例子：一个节点 10 个样本，8 个良性、2 个恶性。

```text
Gini = 1 − (0.8² + 0.2²) = 0.32
```

公式注释：0.32 表示混杂程度，不能读成“错误率是 32%”。如果统一预测良性，该节点训练错误率其实为 2／10=20%。

一次切分后的不纯度要按左右子节点大小加权：

```text
G_after = (n_L / n)G_L + (n_R / n)G_R
ΔG = G_parent − G_after
```

公式注释：`n` 是父节点样本数；`n_L`、`n_R` 是左右子节点样本数；`G_L`、`G_R` 是对应不纯度；`ΔG` 是不纯度下降量。算法在允许的候选特征与阈值中，寻找下降量较大的切分。

继续上面的 8 良性、2 恶性例子：若左边分出 6 个全良性，右边剩 2 良性、2 恶性，则切分后不纯度为 `(6/10)×0 + (4/10)×0.5=0.2`，下降 `0.32−0.2=0.12`。

**要理解到的程度：**会说明“树希望子节点更纯，但必须考虑子节点人数”；不要求背出所有候选阈值的搜索算法。普通决策树是逐节点贪心选择，并不保证得到全局最优的整棵树。

### 3.4 深度、欠拟合与过拟合

树深可以理解为从根到叶最多经过多少次切分。`max_depth=1` 通常称为树桩。

- **欠拟合**：规则过于简单，连训练数据的重要规律都没有学到。
- **过拟合**：连训练数据中的偶然波动都记住，对新数据的表现却不再改善。
- **泛化**：对未参与训练、符合目标应用范围的数据仍然有效。

课件给出的 WDBC 示例结果如下，属于教学参考，不是本次重新运行结果：

| 最大深度 | 训练准确率 | 验证准确率 | 怎样读 |
|---|---:|---:|---|
| 1 | 0.933 | 0.912 | 规则较粗 |
| 2 | 0.956 | 0.956 | 复杂度增加，验证表现改善 |
| 3 | 0.979 | 0.974 | 这次划分中验证准确率最好 |
| 4 | 0.988 | 0.965 | 训练继续提高，验证下降 |
| 不限 | 1.000 | 0.965 | 训练全对，不等于泛化最好 |

**不能背成“深度 3 永远最好”。**最优深度取决于数据、指标和划分；CTG 要做自己的实验。普通树放宽深度限制后通常会更贴合训练数据，但验证曲线不保证单调。

### 3.5 为什么单棵树不稳定

如果两个特征都很适合当第一道问题，训练样本稍有变化，最优切分就可能从一个特征变成另一个。根节点一变，下面整棵树都可能变化。

课件在 WDBC 上的 10 次 bootstrap 示例中，根节点分别选到 `worst perimeter`、`worst area`、`worst radius` 和 `mean concave points`。这些变化说明树对训练样本扰动敏感，不表示算法发生故障。

**【必会操作·必须完成】工作单 A：**

1. 固定训练与验证数据，拟合深度 1、2、3、4、不限的树。
2. 同时记录训练和验证指标，不能只记训练分数。
3. 多次对训练集有放回重抽样，分别拟合浅树。
4. 记录每次根节点特征、阈值；观察结构与预测是否变化。
5. 写出结论：“单棵深树可以拟合训练数据，但对训练数据变化敏感，因此需要考虑降低方差。”

### 3.6 为什么树通常不需要标准化

标准化是把各特征调整到可比较的尺度，常用公式：

```text
z = (x − μ_train) / s_train
```

公式注释：`x` 是原始数值；`μ_train` 是训练部分的均值；`s_train` 是训练部分的标准差；`z` 是标准化结果。验证和测试只应用训练时算出的均值与标准差，不能重新用它们自身拟合。

树主要比较数值的大小顺序。把厘米改成毫米，样本排序不变，相应调整阈值即可，通常不改变可实现的切分。因此树一般不需要为统一尺度而标准化。

RBF-SVM 依赖距离，量级较大的特征可能主导距离；带正则化的逻辑回归也受特征尺度和优化过程影响。因此本课对 LR 和 SVM 使用折内标准化。这是本课合适的实践要求，不是说未标准化的逻辑回归在数学上完全不能拟合。

**本节过关：**会沿树预测、计算叶节点概率、解释 Gini、解释为什么训练全对仍可能不好。

## 4. 集成为什么可能有效：投票、多样性与方差

**【核心重点·必须理解】对应：课件第 7–8 页；工作单 B。这是整节课的理论中心。**

### 4.1 硬投票、软投票与加权

**硬投票**先看每个模型给出的类别，再数票。例如 `[1,1,0]` 的多数票是 1。偶数个模型可能平票，需要事先约定规则。

**软投票**先平均各模型的正类概率，再按约定阈值分类。

```text
p̄(x) = [p₁(x) + p₂(x) + … + p_B(x)] / B
本课手算：若 p̄(x) ≥ 0.5，则预测 1；否则预测 0
```

公式注释：`x` 是同一个待预测样本；`B` 是模型数量；`p_b(x)` 是第 b 个模型给出的正类概率；`p̄(x)` 是平均概率。阈值 0.5 是本课手算约定，不是所有问题都必须采用的阈值；实际软件在恰好平票时可能有自己的规则。

软投票保留了模型“多倾向某一类”的信息，但依赖概率估计的质量，**并不保证总比硬投票好**。不同模型的分数不能未经处理就当概率平均。

如果模型权重不一样：

```text
p̄_weighted(x) = [w₁p₁(x) + … + w_Bp_B(x)] / (w₁ + … + w_B)
```

公式注释：`w_b` 是第 b 个模型的非负权重，权重和应大于 0；权重越大，影响越大。权重如果需要选择，也只能在开发数据内选择，不能根据测试标签调整。

### 4.2 工作单 B 四个样本的完整手算

| 样本 | 真值 | 三模型类别 | 硬投票 | 平均正类概率 | 软投票 | 解读 |
|---|---:|---|---:|---:|---:|---|
| A | 1 | 1、1、0 | 1，对 | (0.80+0.70+0.45)/3=0.650 | 1，对 | 两种投票都对 |
| B | 0 | 0、1、1 | 1，错 | (0.20+0.60+0.65)/3≈0.483 | 0，对 | 多数票错，概率平均后判对 |
| C | 1 | 0、1、1 | 1，对 | (0.35+0.75+0.80)/3≈0.633 | 1，对 | 两种投票都对 |
| D | 0 | 0、0、1 | 0，对 | (0.15+0.25+0.70)/3≈0.367 | 0，对 | 两种投票都对 |

样本 B 中，两个判 1 的模型只给出 0.60 和 0.65，而判 0 的模型给出 0.20；把概率一起平均后低于 0.5。因此不能只凭“两个模型支持 1”判断软投票的结果。

本课 sklearn 随机森林的分类采用**先平均各棵树的类别概率，再选类别**，不能简单地把它的实现描述成每棵树只投一个类别票。

### 4.3 偏差和方差究竟是什么

| 概念 | 直观含义 | 常见例子 |
|---|---|---|
| 偏差 bias | 模型学习能力或假设带来的系统性偏离 | 用过于简单的规则描述复杂关系 |
| 方差 variance | 换一批训练数据后，模型预测变化多大 | 单棵深树换样本后规则和预测大变 |
| 不可约噪声 | 现有输入无法完全解释的随机性或标签误差 | 信息缺失、测量误差、判读差异 |

“偏差低、方差高”是对充分生长的树常见特点的概括，不能不看数据就断定每一棵树都如此。这里的方差指**重复训练产生的预测波动**，不是原始特征列的方差，也不是某次模型错分了多少人。

**为什么平均通常不直接消除共同偏差？**假设多个模型都把某类样本的概率系统性高估 0.2，平均之后仍可能高估 0.2。平均善于抵消方向不一致的波动，无法自动修复所有模型共同遗漏的规律。

### 4.4 必须理解的方差公式

```text
Var(平均预测) = ρσ² + (1 − ρ)σ² / B
```

公式注释：

- `Var` 表示方差，即预测波动大小。
- `B` 是参与平均的模型数量。
- `σ²` 是单个模型预测的方差；此简化公式假设各模型方差相同。
- `ρ` 是不同模型预测波动的两两相关系数，简化假设各对相关性相同。
- 公式针对同一个预测位置、在重复训练等随机性下讨论。它是理解机制的简化模型，不是直接套入准确率计算的公式。

本课可以用“错误是否同步”帮助理解 `ρ`，但严格说，公式中的相关性是预测随机变量的相关性，不等于随手计算的两个错误率的相关性。

**读懂公式的三个结论：**

1. **加模型数有边际递减。**`B` 增大时第二项缩小，但第一项不变。
2. **在此假设下，B 很大时趋向 ρσ²。**如果 `ρ=0`，方差变成 `σ²/B`；如果 `ρ=1`，方差仍是 `σ²`，平均没有降方差收益。
3. **想继续降低波动，除了加树，还要降低相关性。**这正是随机森林引入特征随机化的动机。

数值例子：设 `σ²=0.04`、`ρ=0.6`。

```text
B=10：方差 = 0.6×0.04 + 0.4×0.04/10 = 0.0256
B=100：方差 = 0.6×0.04 + 0.4×0.04/100 = 0.02416
B 很大：方差趋向 0.024
```

公式注释：从 10 棵加到 100 棵有改善，但接近相关性决定的下限后，继续加树的收益很小。此例的方差单位取决于原预测量，不是“准确率提高 2.4%”。

### 4.5 为什么 bagging 常配深树，而非稳定的逻辑回归

深树常有较强拟合能力，但训练样本扰动引起的变化大，平均后可能明显受益。逻辑回归在不少小型、近似线性且正则化适当的问题上已经比较稳定，重复抽样再平均往往收益有限。

这是适用条件，不是数学禁令。逻辑回归也可以 bagging，只是本课要把精力放在更能展示降方差机制的树上。

**本节过关：**会手算两种投票，能解释“模型多”和“模型彼此不同”为什么都重要，能说出方差公式的下限。

## 5. Bootstrap：有放回抽样与 63.2%／36.8%

**【核心重点·必须理解】对应：课件第 9 页；工作单 C。**

### 5.1 “有放回”是什么意思

从原训练集抽一条记录，抽完仍允许它下一次再被抽到。原训练集有 n 条记录，一次标准 bootstrap 抽 n 次，得到的训练表仍有 n 行，但其中会出现重复，也会漏掉一些原记录。

```text
原索引：[1,2,3,4,5]
一次抽样：[2,2,5,1,2]
```

例子注释：抽到 5 次，不同记录只有 `{1,2,5}`；记录 2 出现 3 次；记录 3、4 没被抽到，称为这一次抽样的 OOB（out-of-bag，袋外）记录。重复会改变记录在本轮训练中的影响，不会创造新的生物医学信息。

本次抽样不同记录占比是 `3/5=60%`，袋外比例是 `2/5=40%`。二者不是每次固定。

### 5.2 为什么大样本时约有 36.8% 袋外

```text
某条记录一次未被抽中的概率 = 1 − 1/n
连续抽 n 次仍未抽中的概率 = (1 − 1/n)ⁿ
不同记录占比的期望 = 1 − (1 − 1/n)ⁿ
```

公式注释：`n` 是原训练记录数，每次等概率、有放回抽样，共抽 n 次。第二式同时是袋外比例的期望；第三式是至少出现一次的不同记录比例的期望。**期望是多次抽样的平均规律，不是某次抽样的固定比例。**

```text
n 较大时：(1 − 1/n)ⁿ ≈ e⁻¹ ≈ 0.368
因此：不同记录占比 ≈ 1 − 0.368 = 0.632
```

公式注释：`e` 是自然常数，约 2.718；不要求推导极限。63.2% 和 36.8% 是大样本近似。

**这里尤其容易做错：工作单用 n=5 演示时，精确期望不是 63.2%／36.8%。**

| 原样本数 | 不同记录占比期望 | 袋外比例期望 |
|---:|---:|---:|
| 5 | 1−(4/5)⁵=67.232% | (4/5)⁵=32.768% |
| 341（WDBC train） | 约 63.266% | 约 36.734% |
| 很大 | 约 63.2% | 约 36.8% |

因此，若模拟 1,000 次、每次从 5 条抽 5 条，平均值应靠近 67.2%／32.8%；换成几百条样本，才会接近课件常说的 63.2%／36.8%。

### 5.3 【必会操作】1,000 次抽样模拟

下面使用 Python 标准库，不依赖机器学习包：

```python
import random

rng = random.Random(1010)       # 固定种子，便于复现
for n in (5, 341):
    unique_ratios = []
    oob_ratios = []
    for _ in range(1000):
        drawn = [rng.randrange(n) for _ in range(n)]
        unique_ratio = len(set(drawn)) / n
        unique_ratios.append(unique_ratio)
        oob_ratios.append(1 - unique_ratio)
    theoretical_oob = (1 - 1 / n) ** n
    print("n =", n)
    print("不同记录比例均值：", sum(unique_ratios) / len(unique_ratios))
    print("袋外比例均值：", sum(oob_ratios) / len(oob_ratios))
    print("袋外比例理论期望：", theoretical_oob)
```

代码注释：`set(drawn)` 删除重复索引，用来数“有多少条不同的原记录被抽到”。随机种子控制随机过程，使同一环境下更容易复现；种子本身不让模型更可靠。有限次模拟只会接近理论值，不需要最后几位完全一致。

### 5.4 Bootstrap 不等于交叉验证

Bootstrap 通过重复与遗漏来制造重抽样数据；普通 K 折交叉验证把记录分到不同折，一轮的训练部分通常没有这种抽样重复。两者都可用于研究波动，但操作和目的不同，不能混叫。

## 6. Bagging 与 OOB：怎样训练，怎样评价

**【核心重点·必须理解】对应：课件第 9–10 页；工作单 C–D。**

### 6.1 Bagging 的完整过程

Bagging 是 bootstrap aggregating 的简称，可以记成“重抽样 + 聚合”。

1. 从原训练集 bootstrap 出第一份数据，训练第一棵树。
2. 独立重复这个过程，得到 B 份重抽样数据和 B 棵树。
3. 对同一个新样本，让所有树分别预测。
4. 回归任务可平均预测值；分类任务可投票或平均概率。本课树集成主要看概率平均。

**为什么可以并行？**第 20 棵树不需要知道第 19 棵树预测错了什么，每棵树的拟合任务相互独立。需要注意，bootstrap 数据彼此可以重叠；“可独立训练”不意味着各棵树的预测在统计上完全独立。

本课“全特征 bagging”指节点切分时可考虑全部特征，目的是先观察样本重抽样与平均本身的作用。

### 6.2 OOB 预测是怎样得到的

**标准的集成 OOB 评价，应以每条记录为单位汇总预测：**

1. 对训练记录 i，找出所有训练时没有抽到 i 的树。
2. 只用这些树预测 i，平均概率或聚合类别。
3. 对其他训练记录重复上述步骤。
4. 用各记录的 OOB 预测与真实标签计算总体指标。

例子：训练记录 7 被树 1、2 抽到了，但没有被树 3、4、5 抽到；它的 OOB 预测只能来自树 3、4、5。

**不能先让包含记录 i 的树预测 i，再把结果叫 OOB；也不能把“各树分别算一次 OOB 准确率再平均”视为与上述集成 OOB 指标完全相同。**树太少时，部分记录可能没有足够的 OOB 树，需要留意软件提示。

### 6.3 OOB 能代替什么，不能代替什么

在观察记录近似独立、抽样机制适当的前提下，OOB 能在不额外保留验证集的情况下，对 bagging／森林的泛化表现作内部估计，也可辅助开发阶段选择参数。

但它不能代替：

- 协议锁定后的独立测试集；反复根据 OOB 调参也会产生选择影响。
- 新医院、新时期或新人群的外部验证。
- 对分组结构有针对性的验证设计。

**CTG 的关键限制：**普通森林的 OOB 按“行”抽样。一条片段虽没进入某棵树，同一录音的其他片段却可能进入，所以该片段并非来自真正未见录音。OOB 可能偏乐观，应以按录音分组的验证和 CV 为主。

### 6.4 实际代码中的一个指标细节

sklearn 分类森林默认 `oob_score=True` 得到的 `oob_score_` 是 OOB 准确率；演示脚本也把它命名为 `oob_accuracy`。这不是 OOB ROC-AUC，不能拿它与验证 ROC-AUC 的数值直接比较高低。

**本节过关：**会画出 bagging 的训练与聚合流程；能说清“一条记录的 OOB 预测由哪些树给出”；能解释 CTG 的普通 OOB 为什么有局限。

## 7. 随机森林：在 bagging 之外多做了一件事

**【核心重点·必须理解】对应：课件第 10、12 页；工作单 D。**

### 7.1 两层随机性

| 方法 | 训练记录 | 每个节点可选的切分特征 |
|---|---|---|
| 单棵树 | 原训练集 | 通常全部特征 |
| 本课全特征 bagging | 每棵树一份 bootstrap 数据 | 全部特征 |
| 本课随机森林 | 每棵树一份 bootstrap 数据 | 每个节点随机抽取部分特征作为候选 |

随机森林不是“先随机选一批特征，然后整片森林只能用这一批”。**本课核心是每个节点重新随机抽候选特征，再从候选中选择切分。**

`max_features="sqrt"` 表示候选特征数量取总特征数平方根附近的整数。WDBC 的 30 个特征在 sklearn 中对应 5 个候选；CTG 的 21 个特征对应 4 个候选。软件在无法找到有效切分等边界情况下有实现细节，这里先掌握随机限制候选的主要机制。

### 7.2 为什么特征随机化可能有用

如果某个特征特别强，所有树可能都在顶部选它，结果即使重抽样，树仍然相似。每个节点限制候选特征，会让部分树尝试其他有用特征，降低树之间的相关性 `ρ`，使平均更有效。

代价是单棵树可能变弱。因此森林是在“单树能力”和“树之间差异”之间折中，不能把“越随机越好”当作结论。

当多个特征高度冗余时，不同特征仍可能表达同一信息，随机森林未必明显优于全特征 bagging。工作单要你验证这种差异，而不是预先认定森林一定赢。

### 7.3 树越多会发生什么

从 1 棵加到 10、50、100、300 棵，通常平均预测逐渐稳定，表现改善后进入平台；有限验证集上的 AUC 仍可能上下波动。

“树多不会导致过拟合”应准确理解为：**在其他设置固定时，增加 bagging／森林树数主要让平均更充分，通常不像 boosting 那样因持续追踪训练不足而出现典型的轮数过拟合。**这不保证验证指标单调上升，也不意味着森林本身绝不会过拟合。

森林依然可能受叶节点太小、数据泄漏、目标与人群差异等影响。树数更多还会增加训练时间、预测成本和存储需求。

### 7.4 【必会操作】完成工作单 D 的比较

固定划分、特征和指标，比较：单树、100 棵全特征 bagging、100 棵 `sqrt` 随机森林。至少记录验证 AUC、balanced accuracy、预测 SD 或类别翻转率。

再把树数改为 1、10、50、100、300，记录曲线。回答三件事：

1. 与单树比，平均是否改善了表现和稳定性？
2. 与 bagging 比，特征随机化在这份数据上是否带来额外收益？
3. 继续加树的收益在哪里开始变小，是否值得增加成本？

本课演示中单树为深度 4，bagging／森林用的基树可以更深，因此这是实用模型配置的比较。若要更严格隔离特征随机化，可补充比较同一 `RandomForestClassifier` 的 `max_features=1.0` 与 `"sqrt"`，保持其他参数一致，减少实现和配置差异的影响。

## 8. Boosting：下一轮有针对性地修正当前不足

**【核心重点·必须理解】对应：课件第 11–12 页；工作单 E。**

### 8.1 与 bagging 的根本区别

Bagging 的多个模型分别训练，最后平均；boosting 是前一阶段的结果影响下一阶段的训练目标，再把阶段结果累加。它的典型方向是逐轮增强拟合能力、降低偏差，但实际也涉及方差与正则化，不能理解成“只影响偏差”。

本课需要分别理解 AdaBoost 和 Gradient Boosting，不能只背一句“后面关注前面的错误”就结束。

### 8.2 AdaBoost：改变训练样本的关注程度

最初给样本相同权重。拟合一个简单分类器后，错分样本的相对权重提高，下一轮就更关注它们；最后对各轮分类器加权投票。

如果一直被错分的记录是错误标签或难以解释的噪声，算法也可能持续追着它们学习，这是 AdaBoost 对噪声可能敏感的原因。

**【了解拓展·不要求推导】经典二分类 AdaBoost 的一组写法：**

```text
α_t = ½ ln[(1 − ε_t) / ε_t]
w_i,new ∝ w_i,old × exp[−α_t y_i h_t(x_i)]
```

公式注释：这里为公式方便，标签 `y_i` 和分类器输出 `h_t(x_i)` 使用 −1／+1 编码，与数据文件的 0／1 编码不同；`ε_t` 是本轮按当前权重计算的错误率；`α_t` 是该分类器最终投票的权重；`ln` 是自然对数；`exp` 是指数函数；`∝` 表示还需要把全部权重归一化，使权重和为 1。

预测正确时 `y_i h_t(x_i)=+1`，权重乘一个较小因子；预测错误时乘积为 −1，权重乘一个较大因子。当 `0<ε_t<0.5` 时，`α_t>0`。零错误等边界情况由算法另行处理。不同编码与实现可能把常数放在不同位置，课堂不要求照公式重写 sklearn。

**核心只需掌握：样本权重变化、分类器加权组合、训练顺序依赖。**

### 8.3 Gradient Boosting：沿损失下降方向增加新树

“损失函数”是给预测错误定量打分的规则。梯度表示局部变化方向；负梯度指使损失下降的方向。梯度提升的新树拟合这个修正方向。

在二分类中，先用一个实数分数 `F(x)`，再转成概率：

```text
p = 1 / [1 + exp(−F)]
```

公式注释：`F` 是模型当前的原始分数，在这里按 log-odds（对数几率）理解；`p` 是正类概率；`exp` 是指数函数。`F=0` 时 `p=0.5`；F 越大，p 越接近 1。

对二分类 log-loss，新树拟合的负梯度方向为：

```text
r_i = y_i − p_i
```

公式注释：`r_i` 是第 i 条记录当前的负梯度，也常叫伪残差；`y_i` 使用 0／1 标签；`p_i` 是当前预测正类概率。这里是**对原始分数 F 求导**得到的方向，不是直接对 p 求导的结果。log-loss 的定义在第 10 节解释。

| 真值 y | 当前概率 p | y−p | 应怎样修正 |
|---:|---:|---:|---|
| 1 | 0.20 | +0.80 | 明显提高正类倾向 |
| 1 | 0.90 | +0.10 | 方向仍向上，但修正较小 |
| 0 | 0.80 | −0.80 | 明显降低正类倾向 |
| 0 | 0.10 | −0.10 | 方向仍向下，但修正较小 |

**已分类正确的记录也可能需要修正**，所以梯度提升不是“只训练错分样本”。拟合残差方向时使用回归树，因为目标是连续数值，可以为负；最终整体仍是分类模型。

简化的阶段更新写为：

```text
F_t(x) = F_(t−1)(x) + ηh_t(x)
```

公式注释：`t` 表示第 t 轮；`h_t` 是这一轮学到的修正函数；`η`（eta）是学习率，对应 `learning_rate`。真实实现还可能对叶节点值作损失相关更新，但方向都是把当前修正加到原始分数上，再转概率，**不是直接无限往概率上加 y−p**。

### 8.4 学习率与轮数为什么要一起看

- 学习率大：每次迈步较大，可能较快学到规律，也可能更快追随噪声。
- 学习率小：每次修正较谨慎，通常需要更多轮。
- 轮数太少：可能仍然欠拟合。
- 轮数太多：可能训练损失继续下降，验证损失反而升高。

`learning_rate × n_estimators` 提醒你两者要联合考虑，但**不能把乘积相同当成两个模型等价**。每轮都依赖前面的结果，学习路径也会变化。

轮数用开发阶段的验证或合适的 early stopping（早停）决定，不看测试集。CTG 若用早停，早停所用验证数据也应按录音隔离，不能默认一个按行随机切分的内部验证集就满足分组要求。

### 8.5 为什么 AUC 没变，log-loss 却可能变差

假设两轮模型对样本的排序相同，但后者把一个实际为 0 的样本从 0.8 进一步推到 0.99。排序可能没变，AUC 因此变化很小；但“更自信地预测错了”，log-loss 会明显变大。

所以观察 boosting 轮数时，不能只看训练准确率或 AUC，还应看验证 log-loss。课件相关材料中的 WDBC 示例提示了这种现象；具体最优轮数要用自己的开发集结果确定。

### 8.6 XGBoost、LightGBM 与 sklearn 梯度提升是什么关系

**【了解拓展·不要求安装】它们都属于梯度提升树家族，不是与 boosting 无关的新原理。**

| 实现 | 与本课机制的关系 | 主要应知道什么 |
|---|---|---|
| sklearn `GradientBoostingClassifier` | 经典梯度提升树实现 | 适合直观理解逐轮拟合负梯度 |
| sklearn `HistGradientBoostingClassifier` | 使用直方图分箱的梯度提升实现 | 通常更适合较大数据；支持缺失值等功能 |
| XGBoost | 高效、正则化的梯度提升树实现 | 利用一阶和二阶信息，显式控制树复杂度，提供高效计算与缺失值处理 |
| LightGBM | 高效的梯度提升树实现 | 常见实现用直方图与按叶生长策略，支持二阶信息及多种复杂度控制；小数据上也要防止过拟合 |

不能把所有 sklearn 树提升实现都说成支持缺失值；经典 `GradientBoostingClassifier` 与直方图实现的能力不同。各库参数名也不完全一致，例如 XGBoost 的 `min_child_weight` 不等于所有库都有同名参数。

XGBoost 的目标可以作如下概念性理解：

```text
优化目标 = 预测损失 + 树复杂度惩罚
```

公式注释：预测损失要求贴近标签；复杂度惩罚限制树过分复杂，有助于控制过拟合。二阶信息可以理解为除了知道往哪个方向改，还利用损失局部弯曲程度帮助确定改多少；本课不要求推导。

**本节过关：**能分别解释 AdaBoost 的权重变化、梯度提升的 y−p、为什么顺序训练、为什么学习率和轮数要联合选择。

## 9. 关键超参数：调的是什么，为什么调

**【核心重点·必须理解用途；不要求穷举搜索】对应：课件第 12 页；工作单 A、D、E。**

| 参数 | 主要适用方法 | 控制什么 | 调整时应观察什么 |
|---|---|---|---|
| `max_depth` | 单树、森林基树、梯度提升基树 | 每棵树最多切分多深 | 太浅可能欠拟合，太深可能记住噪声 |
| `min_samples_leaf` | 多数树模型 | 每个叶节点至少保留多少训练样本 | 调大通常使预测更平滑，但可能损失细节 |
| `n_estimators` | bagging、森林、boosting | 树／阶段数量 | 森林看平台与成本；boosting 还要防止轮数过多 |
| `max_features` | 森林、bagging 等 | 特征使用范围；具体抽取层级依实现而异 | 随机森林控制节点候选特征，影响单树强度和树间相关性 |
| `learning_rate` | AdaBoost、梯度提升等 | 每轮修正或贡献的强度 | 与轮数联合选择，观察验证损失 |
| `subsample` | 经典梯度提升等 | 每轮用于训练的样本比例 | 小于 1 引入随机性，可改变偏差与方差的折中 |
| `C` | 本课 RBF-SVM | 正则化强弱的反向参数 | C 大通常更强调拟合训练数据，需用验证选择 |
| `gamma` | RBF-SVM | 单个样本影响范围对应的核尺度 | 大时边界可更局部、更复杂；小则影响更宽 |

**重要细节：**`BaggingClassifier(max_features=...)` 通常是在每个基学习器层面抽取特征；`RandomForestClassifier(max_features=...)` 是每个切分节点的候选特征数。参数同名不代表机制完全相同。本课 bagging 设置为全部特征，森林才引入节点候选随机化。

参数名称相同也未必代表完全相同的策略。例如梯度提升的阶段依赖前面结果，森林的树则可独立拟合，不能把两者的 `n_estimators=100` 看成同样的复杂度。

建议先按课件和脚本预设运行，再一次只改少量设置、写下理由。不要为了赢过某个模型而无休止尝试；尝试很多配置本身也会使开发阶段的最佳分数偏乐观。

## 10. 模型表现怎么看：不要只盯 accuracy

**【核心重点·必须理解】对应：课件第 15、17 页；工作单 D–F。**

### 10.1 先看混淆矩阵

正类统一指本课标签 1：WDBC 为恶性，CTG 为病理型。

| 真实类别＼预测类别 | 预测 0 | 预测 1 |
|---|---:|---:|
| 真实 0 | TN，真阴性 | FP，假阳性 |
| 真实 1 | FN，假阴性 | TP，真阳性 |

- TP：正类被正确识别。
- TN：负类被正确识别。
- FP：把负类误判成正类，即误报。
- FN：把正类误判成负类，即漏报。

本课中正类有明确的数据标签含义，不要自动把 FP、FN 扩大解释成已经发生的临床后果。

### 10.2 Accuracy、敏感度、特异度和 balanced accuracy

```text
Accuracy（准确率） = (TP + TN) / (TP + TN + FP + FN)
Sensitivity（敏感度／正类召回率） = TP / (TP + FN)
Specificity（特异度） = TN / (TN + FP)
Balanced accuracy（平衡准确率） = (Sensitivity + Specificity) / 2
```

公式注释：accuracy 看全部记录中预测正确的比例；敏感度看真实正类中找出了多少；特异度看真实负类中正确排除了多少；平衡准确率给正负两类相同的权重。分母为零时有关指标无法按普通公式计算，需要检查数据与软件约定。

假设 100 条记录中有 10 条正类、90 条负类，某模型全部预测 0：

```text
Accuracy = 90/100 = 90%
Sensitivity = 0/10 = 0%
Specificity = 90/90 = 100%
Balanced accuracy = (0% + 100%)/2 = 50%
```

公式注释：看起来 90% 准确，却一个正类都没找到，这说明在类别不平衡时 accuracy 容易误导。CTG 若全部预测 0，按全数据比例计算准确率约 91.7%，也不代表有用的病理型识别能力。

### 10.3 ROC-AUC 衡量排序，不等于准确率

ROC 曲线观察不同阈值下，正类检出率与负类误报率的变化。AUC 是曲线下面积。

可以用下面的概率表达理解二分类 AUC：

```text
AUC = P(s_positive > s_negative) + ½P(s_positive = s_negative)
```

公式注释：`s` 是模型给出的正类排序分数；随机选一个真实正类和一个真实负类，AUC 衡量正类得分更高的概率，并对并列给半分。这里的概率是对数据中正负样本配对的排序解释，不是某个人患病概率。

- AUC 约 0.5：没有有用排序时的常见基准。
- AUC 接近 1：正负类排序很好。
- AUC=1：该评价数据上的排序完美，仍不保证概率准确、0.5 阈值下全对，或未来数据上完美。

**计算 AUC 应使用概率或连续分数，而不是先压成 0／1 类别。**两模型 AUC 相近时，默认阈值下的 balanced accuracy、敏感度仍可能差很多。

### 10.4 为什么 CTG 建议加 PR 指标

Precision（精确率）回答：被模型判为正类的记录中，真正正类占多少。

```text
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
```

公式注释：Precision 的分母是“预测正类人数”；Recall 的分母是“真实正类人数”，与敏感度相同。不要把 precision 和 sensitivity 混淆。

PR 曲线观察不同阈值下 precision 与 recall 的折中。正类很少时，它更能直接暴露“找出正类时伴随了多少误报”的问题。它受正类比例影响，不能随意跨人群、跨数据集比较。

**本项目的口径：**演示脚本的交叉验证使用 `average_precision`，即 AP（Average Precision），列名为 `average_precision_mean`。教师材料把这一项概括成 PR-AUC。AP 与用梯形法计算 PR 曲线面积并非严格相同，正式记录建议写“AP（PR 汇总指标）”，并保持所有模型计算口径一致。无信息排序的常见 PR 参考水平约为正类比例；不要把所有 PR 指标的基准都记成 0.5。

### 10.5 Log-loss：奖励可信概率，惩罚自信的错误

```text
Log-loss = −(1/n) Σ_i [y_i ln(p_i) + (1−y_i) ln(1−p_i)]
```

公式注释：`n` 是评价样本数；`Σ_i` 表示把每条记录的项相加；`y_i` 为 0／1 真值；`p_i` 是正类概率；`ln` 为自然对数。log-loss 越小越好，和 AUC、准确率“越大越好”的方向相反。实际计算会处理概率接近 0 或 1 时的数值问题。

真实为 1 时，单样本损失为 `−ln(p)`：预测 p=0.9 时约 0.105；预测 p=0.01 时约 4.605。后者既错又非常自信，惩罚就大。

**本节过关：**知道每个指标在问什么；知道 AUC 高、阈值分类好、概率可信是相关但不同的事情。

## 11. 特征重要性：模型依赖什么，为什么容易误读

**【核心重点·必须理解】对应：课件第 13 页；工作单 D。**

### 11.1 不纯度重要性

树每次用一个特征切分，都可能降低不纯度。把该特征在各节点、各棵树中带来的加权不纯度下降汇总，再作归一化，就得到常见的 `feature_importances_`。

```text
某节点的贡献 ∝ 该节点样本权重占比 × 该次切分的不纯度下降
某特征的重要性：汇总它参与切分的贡献，并按实现归一化、跨树汇总
```

公式注释：`∝` 表示概念上的比例关系；样本权重占比避免把极小叶节点的一次改善与大节点改善等同看待。此处为机制说明，具体归一化顺序以软件实现为准。

优点是计算快、训练后即可查看。局限包括偏向可选切分较多的特征，例如不同取值很多的连续变量；相关特征的重要性可能被分摊，或因切分竞争而主要集中在其中某个变量。

因此，“重要性 0.2”不是“这个特征造成了 20% 的疾病”，也不是“单独用它准确率就是 20%”。

### 11.2 置换重要性

固定已经拟合好的模型，在验证数据中打乱一个特征的行顺序，破坏它与标签和其他特征的对应关系，再看表现下降多少。

```text
I_j = 原始验证 AUC − 打乱第 j 个特征后的验证 AUC
```

公式注释：`I_j` 是第 j 个特征在所选指标下的置换重要性。正值越大，表示打乱后损失越明显。本课用 AUC，越大越好，因此按“原始减打乱后”计算；若用损失指标，要相应统一方向。

置换通常重复多次，报告平均下降与波动。出现接近零或负值并不矛盾，可能是模型基本没依赖它、相关特征能够替补，或有限样本与随机置换带来的波动。负值也不自动证明“删掉它一定有益”。

### 11.3 高度相关特征为什么难解释

半径、周长、面积可能共同表达肿块大小。

- 训练时，几个变量都能帮助切分，不纯度重要性可能分摊或集中。
- 预测时，单独打乱周长，模型仍能利用半径和面积，AUC 降幅可能很小。
- 所以“单个变量置换重要性小”不等于“这一组大小信息完全没用”。

课件的 WDBC 例子中，这几类大小特征高度相关；不纯度重要性不低，但单独置换时 AUC 下降很小。先看相关矩阵，再解释两种重要性不一致，比直接宣称某一种排名错误更合理。

还要注意，打乱一个变量可能创造现实中不常见的变量组合；置换重要性描述的是特定模型、特定数据、特定评价方式下的依赖，仍有局限。

### 11.4 【必会操作】工作单要求的完成方式

1. 用训练数据拟合森林，提取不纯度重要性前几名。
2. 在固定验证集上计算重复置换重要性，记录均值与波动。
3. 先在训练数据上检查特征相关矩阵，标出高度相关的特征组。
4. 对比排名是否一致；用“切分竞争／分摊”和“替补”解释可能差异。
5. 用一句边界说明收尾：“这里解释模型预测依赖，不证明因果作用。”

**本节过关：**能解释两种重要性怎么来、为何不同，以及为什么都不能直接给出生物医学因果结论。

## 12. 稳定性与不确定性：三种问题不能混为一谈

**【核心重点·必须详细理解】对应：课件第 16 页；工作单 G。**

### 12.1 问题一：换一批训练记录，模型预测会变化多大

固定验证记录，对训练集反复 bootstrap，每次重新拟合模型，再预测同一批验证记录。一个验证样本就会得到多次预测概率。

```text
第 1 次重抽样训练 → 某固定验证样本概率 0.20
第 2 次重抽样训练 → 同一样本概率 0.75
第 3 次重抽样训练 → 同一样本概率 0.35
```

例子注释：样本没换，训练记录发生了变化；这反映训练样本扰动下的预测稳定性。如果同时随意改变算法种子，就又混入算法随机性的变化。本课演示固定模型种子，并让各方法共用同一批抽样索引，主要观察训练样本扰动。

单个固定样本的重复预测 SD 可写为：

```text
p̄_i = (1/R) Σ_r p_(r,i)
SD_i = √[(1/R) Σ_r (p_(r,i) − p̄_i)²]
平均预测 SD = (1/m) Σ_i SD_i
```

公式注释：`R` 是重训练次数，本课演示为 30；`m` 是固定验证样本数；`p_(r,i)` 是第 r 次训练模型对第 i 个验证样本的正类概率；`√` 表示平方根。这里为与脚本一致，SD 使用分母 R，即 NumPy 默认 `ddof=0`；另一种样本 SD 使用 R−1，报告时应说明口径。平均 SD 衡量同一批验证样本的平均预测波动，不是平均预测误差。

### 12.2 本课“类别翻转率”的准确口径

演示脚本对每个验证样本观察 30 次预测：只要至少一次判 0、至少一次判 1，就记为该样本发生类别翻转。最后看这样的样本占验证集多少。

```text
类别翻转率 = 反复训练中曾同时被判成 0 和 1 的验证样本数 / 验证样本总数
```

公式注释：这里先按每次预测概率 `≥0.5` 判 1，再判断是否出现两类。这不是相邻两次预测变化次数的比例，也不是相对于真实标签的错误率。

例子：5 个验证样本中，有 2 个在重复训练中出现过两种类别，则翻转率为 40%。某样本从 0.1 变到 0.4，概率变化明显但都判 0；从 0.49 变到 0.51，SD 可能很小却发生翻转。因此 SD 与翻转率应结合阅读。

**低波动不等于预测正确。**一个每次都给出错误答案的模型也可能非常稳定，所以必须同时看表现指标。

### 12.3 问题二：固定一个模型，评价样本变化时指标波动多大

这一次**不重新训练模型**。先固定模型对某评价集的预测，再对评价记录索引 bootstrap，每次重新计算 AUC 等指标。

```text
固定模型与预测
    → 抽取评价记录索引
    → 每次计算一个指标
    → 用指标分布描述该评价样本抽样下的波动
```

结构注释：模型固定，变的是评价记录及其重复次数。若作百分位区间，常取重复指标的第 2.5 和第 97.5 百分位，形成近似 95% 区间；这不是“95% 的个人预测会正确”。

若比较两个固定模型，应对它们使用相同的抽样索引，研究配对指标差；但仅靠本课五折均值和 SD，不能直接宣称差异具有统计显著性。

CTG 片段相关时，按行 bootstrap 不能充分反映组内依赖，应考虑以录音为单位的聚类 bootstrap 等设计。若在测试集上做这种分析，也应等到协议锁定、教师允许揭示测试标签之后；本课工作单主要要求理解区分，不强制计算完整区间。

### 12.4 问题三：换医院、换时期、换人群会怎样

新环境可能有不同设备、病例构成、测量流程和标签标准。本课内部重抽样没有制造这些变化，不能由此证明外部人群表现。

| 问题 | 变化的对象 | 本课能支持什么 | 不能据此推出什么 |
|---|---|---|---|
| 训练扰动稳定性 | 训练样本，需重新拟合 | 在本数据抽样机制下预测是否稳定 | 固定模型指标的置信区间、个人风险区间 |
| 固定模型指标区间 | 评价样本索引，不重训 | 条件于已拟合模型的评价波动 | 重训、重选模型、外部环境变化的全部不确定性 |
| 外部泛化 | 医院、时间或人群 | 本课只能提出后续验证需求 | 本课内部高分足以证明可部署 |

### 12.5 CTG 稳定性实验还要加的一句说明

现有演示的训练 bootstrap 按“片段行”进行，即使输入是 CTG 也如此。它能描述**本课这种片段重抽样下的敏感性**，不能冒充“新录音层面的严格抽样不确定性”。若研究目标是录音层面的扰动，应补充按 `recording_id` 整组抽样的实验。固定验证集仍应与训练集按录音隔离。

**本节过关：**看到任何“bootstrap 结果”，先问：抽的是训练数据还是评价数据？是否重新拟合？按行还是按组？结论条件于什么？

## 13. 公平比较与选型：如何把结果写成有依据的判断

**【核心重点·必须理解】对应：课件第 14–15 页；工作单 F。**

### 13.1 公平比较需要固定什么

1. **相同记录与标签定义**：不能一个模型预测恶性，另一个模型把良性当正类，却直接比较分数。
2. **相同划分与 CV 折**：尤其 CTG 必须按同一录音分组协议。
3. **合理、无泄漏的预处理**：LR／SVM 在折内标准化，树模型按自身需要处理。
4. **相同评价口径**：同样的正类、AUC 得分类型、阈值规则、AP 计算方式。
5. **清楚的参数和选择范围**：记录哪些是预设，哪些在开发集选择；不能用测试结果改配置。
6. **同时评估代价**：训练／预测成本、解释成本以及结果波动。

公平不意味着所有模型必须用同一个不适合它们的预处理，也不意味着 `100 棵树` 与 `100 轮提升` 必须具有相同复杂度。

### 13.2 本课为什么还要跑逻辑回归和 SVM

简单基线回答“复杂模型是否真的值得”。逻辑回归能作为稳定、易解释的线性基线；RBF-SVM 能提供一种不同的非线性方法。集成胜过单树，不等于已经胜过所有合理基线。

逻辑回归的基本形式可以了解为：

```text
F(x) = β₀ + β₁x₁ + … + β_dx_d
p(x) = 1 / [1 + exp(−F(x))]
```

公式注释：`d` 是特征数；`β₀` 是截距；`β_j` 是第 j 个特征的系数；`F` 为线性组合；`p` 为转化后的正类概率。模型在原特征的 log-odds 尺度上是线性的。系数解释也依赖其他变量、尺度、相关性与模型设定，不能直接当作因果效应。

RBF-SVM 可先理解成用核方法学习弯曲边界的分类器；本课重点是知道它需要尺度处理，并用连续决策得分算 AUC，不要求推导支持向量优化。

### 13.3 怎样看“均值差是否超过波动”

假设方法 A 的 CV AUC 为 `0.990±0.010`，方法 B 为 `0.988±0.013`。均值差只有 0.002，而各自折间波动约 0.01，不能只按小数点后三位就宣布 A 稳定胜出。

反过来，即便均值差比某个 SD 大，也不能仅凭这个规则宣布“统计显著”。各模型用相同折时，应关注同折的配对表现；需要正式推断时，要选择与数据依赖结构匹配的方法。

本课要求的是：**把差距和波动一起报告，用有限证据作有限判断。**

### 13.4 两套数据为什么可能得出不同建议

下列是 `teacher-reference.md` 的参考结果节选，不是本次执行的新实验。其记录的环境为 sklearn 1.9.0、固定种子 1010；版本与设置差异可能改变数值。A、B 的 CV 都在各自开发集做，B 为按录音分组 CV。

| 模型 | A：CV ROC-AUC 均值±SD | B：分组 CV ROC-AUC 均值±SD | B：CV AP 均值 | B：CV balanced accuracy 均值 |
|---|---:|---:|---:|---:|
| 单树（深度 4） | 0.921±0.033 | 0.866±0.114 | 0.737 | 0.897 |
| Bagging（100 棵） | 0.987±0.013 | 0.978±0.015 | 0.892 | 0.916 |
| 随机森林（100 棵） | 0.989±0.010 | 0.994±0.003 | 0.944 | 0.925 |
| AdaBoost（50 轮） | 0.987±0.014 | 0.988±0.006 | 0.901 | 0.884 |
| 梯度提升（100 轮） | 0.988±0.013 | 0.989±0.005 | 0.938 | 0.928 |
| 逻辑回归 | 0.994±0.010 | 0.990±0.006 | 0.923 | 0.872 |
| RBF-SVM | 0.993±0.010 | 0.980±0.010 | 0.875 | 0.797 |

**方案 A 的合理阅读：**集成比单树明显好，但 LR／SVM 已很好，不能声称复杂树集成一定优于它们。若差异很小而解释需求高，可以优先保留简单模型。

**方案 B 的合理阅读：**RF／GB 在该分组 CV 的 AP 和 balanced accuracy 上优于这些基线，但不同指标的赢家未必相同。例如 GB 的 balanced accuracy 略高于 RF，而 RF 的 AUC、AP 较高。应先明确更重视排序、正类检出、误报还是概率质量，再结合波动作选择。

两套数据都不支持“某算法对所有医学数据最强”。教师参考数字用于理解现象，不能作为你必须跑到的目标分数。

### 13.5 选型经验与代价

| 情形 | 可优先考虑 | 必须同时考虑的代价 |
|---|---|---|
| 样本较少、关系近似线性、需要系数解释 | 逻辑回归 | 可能无法直接表达复杂交互与非线性 |
| 中小样本、边界弯曲 | RBF-SVM | 标准化与 C、gamma 选择；解释成本较高 |
| 表格数据、非线性与交互较多、想先得到稳健基线 | 随机森林 | 比浅树难直接解释；相关特征与 OOB 有局限 |
| 愿意谨慎调参、追求更好表格预测 | 梯度提升及其高效实现 | 学习率、树复杂度和轮数控制；可能追随噪声 |
| 必须给人直接阅读的少量规则 | 浅决策树 | 表现可能有限，结构可能不稳定 |

这些是启动实验的经验，不是最后裁决。最终建议应是“在本数据和协议下，因为什么证据，先选什么；若出现什么证据则改选”。

### 14.5 A：深度实验与根节点变化

```python
rows = []
for depth in (1, 2, 3, 4, None):
    tree = DecisionTreeClassifier(max_depth=depth, random_state=1010)
    tree.fit(X, y)
    rows.append({
        "max_depth": depth,
        "train_accuracy": accuracy_score(y, tree.predict(X)),
        "validation_accuracy": accuracy_score(yv, tree.predict(Xv)),
        "validation_auc": roc_auc_score(yv, tree.predict_proba(Xv)[:, 1]),
    })
print(pd.DataFrame(rows).to_string(index=False))

rng = np.random.default_rng(1010)
for repeat in range(10):
    idx = rng.choice(len(y), size=len(y), replace=True)
    tree = DecisionTreeClassifier(max_depth=2, random_state=1010)
    tree.fit(X.iloc[idx], y.iloc[idx])
    root_feature = tree.tree_.feature[0]
    if root_feature >= 0:
        print(repeat + 1, features[root_feature], tree.tree_.threshold[0])
    else:
        print(repeat + 1, "根节点没有切分")
```

代码注释：`None` 表示不直接限制最大深度；`.iloc[idx]` 允许同一行因重复索引出现多次；`tree_.feature[0]` 是根节点使用的特征序号。树结构接口适合本课堂观察，不要求先熟悉底层实现。这里固定模型种子，让变化主要来自训练行重抽样；CTG 的这一片段仍属于第 12.5 节所述行扰动实验。

### 14.6 E：学习率与轮数曲线

```python
rows = []
checkpoints = {1, 10, 30, 50, 100, 300, 500}
for rate in (0.03, 0.1, 0.3):
    gb = GradientBoostingClassifier(
        learning_rate=rate, n_estimators=500,
        max_depth=3, random_state=1010
    ).fit(X, y)
    stages = zip(gb.staged_predict_proba(X), gb.staged_predict_proba(Xv))
    for stage, (ptr, pva) in enumerate(stages, start=1):
        if stage in checkpoints:
            rows.append({
                "learning_rate": rate,
                "n_estimators": stage,
                "train_log_loss": log_loss(y, ptr, labels=[0, 1]),
                "validation_log_loss": log_loss(yv, pva, labels=[0, 1]),
                "validation_auc": roc_auc_score(yv, pva[:, 1]),
            })
curve = pd.DataFrame(rows)
print(curve.to_string(index=False))
```

代码注释：`staged_predict_proba` 逐阶段输出预测，便于观察同一提升路径，不需要每个轮数都从头训练。此例使用已经按课堂规则隔离的固定验证集；不读取测试集，也没有采用可能按行切分的自动早停。它观察学习曲线，不是全面调参。

看结果时，先找训练 log-loss 是否持续下降，再看验证 log-loss 是否开始上升，以及 AUC 是否同时变化。不能因为示例参考说“50 轮附近”就固定写自己数据的最佳轮数是 50。

### 14.7 D：先看相关矩阵，再解释重要性

```python
corr = X.corr()
pairs = []
for i in range(len(features)):
    for j in range(i + 1, len(features)):
        r = corr.iloc[i, j]
        if abs(r) > 0.9:
            pairs.append((features[i], features[j], r))
print(pd.DataFrame(pairs, columns=["feature_1", "feature_2", "r"]))
```

代码注释：相关系数 `r` 在 −1 至 1 之间，这里使用 Pearson 线性相关；绝对值接近 1 表示强线性相关。0.9 是观察冗余的示例阈值，不是判定因果或所有非线性依赖的标准。常数列可能得到缺失相关系数，需要如实识别。

**【核心重点·必须会解释】对应：工作单 H。**

| 方面 | Bagging（含本课随机森林） | Boosting |
|---|---|---|
| 训练关系 | 各基学习器可独立训练，可并行 | 阶段有顺序依赖；部分库可并行单棵树内部计算，但不消除阶段依赖 |
| 每轮数据／目标 | 通常每棵树一份 bootstrap 数据 | AdaBoost 改变样本权重；GB 拟合当前损失的负梯度，可另带行采样 |
| 基学习器 | 常用较深、低偏差而高方差的树 | 常用树桩或浅树；深度依具体任务与实现选择 |
| 聚合方式 | 平均预测／概率，或类别投票 | 加权组合或逐轮累加修正；不同 boosting 方法细节不同 |
| 主要改进方向 | 通过平均减小训练扰动方差 | 逐轮增强拟合能力，主要降低偏差，同时需控制方差 |
| 噪声敏感性 | 平均通常比单棵深树稳，但不能消除系统性噪声 | 持续强调难例或修正残差，可能追随噪声和错误标签 |
| 增加树数／轮数 | 通常趋向平台，主要增加计算与存储成本 | 可能出现训练更好、验证变差，需要控制轮数 |
| 关键超参数 | 树数、节点候选特征数、叶节点大小、树深度等 | 学习率、轮数、树深度／叶数、采样比例、正则化等 |
| 随机森林的额外机制 | 在 bootstrap 基础上加入节点候选特征随机化 | 特征采样可以存在于某些 boosting 实现中，但不改变顺序修正本质 |

最容易被追问的是：“为什么深树适合 bagging，而 boosting 常用浅树？”回答时把**单树拟合能力、方差、平均、逐轮增强、过拟合控制**连起来，不能只背表格。

### 15.2 250–400 字备忘录需要包含什么

备忘录应回答四项要求：**表现、稳定性、解释成本、验证范围**，并提出一条会改变当前选择的后续证据。

建议写作顺序：

1. 用什么数据、标签和划分协议进行比较。
2. 哪些指标支持当前选择；优势相对谁、大小如何、是否伴随明显波动。
3. 预测稳定性如何；这里采用何种抽样层级与度量。
4. 增加复杂度是否值得；保留哪个简单基线。
5. 结论限于哪里；什么后续结果会让你改选。

下面是可替换的写作模板，不是已经完成的实验报告；替换方括号后按课堂字数要求压缩或展开：

> 我们在［数据名］上预测［正类标签］，沿用固定训练／验证划分，并采用［分层／按录音分组］五折交叉验证；测试标签未参与选择。［模型］的验证［指标］为［数值］，CV 为［均值±SD］，相对［基线］的差距为［数值］。考虑到折间波动，我将其解释为［初步优势／表现接近］。共享 bootstrap 重训练中，［模型］的平均预测 SD 和类别翻转率为［数值］，说明其在本次训练扰动下［较稳定／仍有波动］。不过［复杂模型］的解释成本较高，因此我建议［优先选用某模型／保留多个候选］，并保留［简单模型］作为对照。该结论仅适用于本数据、标签和协议，不能推出因果作用或跨医院有效性。若后续［独立录音／外部人群］评价发现［事先说明的性能、校准或稳定性问题］，我会重新考虑当前选择。

**不要写的句子与替代写法：**

| 不充分或错误的表述 | 更合适的表述 |
|---|---|
| “随机森林最先进，所以选它。” | “在相同协议下，它在某指标上优于某基线，同时比较了波动与代价。” |
| “AUC=1，所以不会误诊。” | “在本验证集上排序完美，仍需检查阈值表现、概率质量与外部验证。” |
| “翻转率低，证明预测正确。” | “翻转率低说明本次扰动下稳定，正确性需另看标签评价。” |
| “ALTV 排第一，证明它导致病理型。” | “本模型在该数据和置换方式下较依赖 ALTV，不代表因果效应。” |
| “OOB 很高，证明新录音也一样。” | “CTG 的行级 OOB 有同录音信息重叠问题，应报告分组验证。” |
| “测试模型排名出来了，我再调整参数。” | “测试用于最终评价；若结果与开发建议冲突，应如实报告并设计后续研究。” |

## 16. 复习时优先抓住这 12 个问题

**这些问题能解释清楚，才算掌握本课主线。**

| 自测题 | 合格答案至少要提到 |
|---|---|
| 1. 一棵树怎样预测？ | 按特征阈值沿根到叶；叶节点比例给出概率估计 |
| 2. 树怎样选择切分？ | 比较候选切分的加权不纯度下降；逐节点选择 |
| 3. 为什么训练全对仍可能不好？ | 训练不等于泛化；可能记住噪声；看验证表现 |
| 4. 硬投票和软投票有什么不同？ | 类别多数与概率平均；样本 B 是不同结果的例子 |
| 5. 平均为什么能降方差？ | 抵消不完全同步的预测波动；B 增大有下限 ρσ² |
| 6. Bootstrap 怎样抽，为什么不全是不同记录？ | 有放回抽 n 次；重复与遗漏；大样本 63.2%／36.8%，n=5 要用精确式 |
| 7. OOB 预测来自谁，CTG 有什么问题？ | 只用未抽到该记录的树；同录音片段可能仍参与训练 |
| 8. 随机森林比 bagging 多什么？ | 每个节点随机限制候选特征，尝试降低相关性 |
| 9. AdaBoost 与 GB 各在修正什么？ | 前者改变样本权重，后者拟合负梯度；log-loss 下 y−p |
| 10. 为什么森林树数与 boosting 轮数不能同样解释？ | 前者主要更充分平均，后者持续顺序增强，需防止轮数过多 |
| 11. 两种特征重要性为什么可能不同？ | 不纯度切分贡献；验证置换性能变化；相关特征竞争、分摊与替补 |
| 12. 怎样证明某模型值得选择？ | 同协议表现、波动、训练稳定性、解释成本与验证范围共同支持 |

### 16.1 最小术语速查

| 术语／缩写 | 中文含义 | 本课要记住的区别 |
|---|---|---|
| Ensemble | 集成学习 | 多个模型如何组合；并不保证更好 |
| Bootstrap | 自助重抽样 | 有放回抽样；既能用于训练，也能用于研究指标波动 |
| Bagging | 自助聚合 | 重抽样后独立训练，再聚合 |
| RF / Random Forest | 随机森林 | 样本随机性 + 节点候选特征随机性 |
| Boosting | 提升 | 顺序修正、逐轮增强 |
| GB / GBDT | 梯度提升／梯度提升树 | 新树拟合损失的负梯度方向 |
| LR | 逻辑回归 | 分类基线，不是线性回归 |
| SVM | 支持向量机 | 本课用 RBF 核；默认决策分数不是概率 |
| CV | 交叉验证 | 轮换训练／验证来评价方法；CTG 要分组 |
| OOB | 袋外 | 对一棵树而言没有被抽入训练的数据 |
| SD | 标准差 | 说明谁在波动：折间指标还是重训预测 |
| ROC-AUC | ROC 曲线下面积 | 排序能力，不是概率校准或固定阈值准确率 |
| BA | Balanced accuracy | 敏感度与特异度的平均 |
| AP | Average Precision | 本脚本的 PR 汇总指标，区别于梯形 PR 面积 |
| Early stopping | 早停 | 用开发阶段验证阻止无益的继续训练 |
| Calibration | 概率校准 | 例如一批给 0.8 的记录中，正类比例是否约为 80%；不由高 AUC 自动保证 |
