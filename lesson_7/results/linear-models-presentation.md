# 线性模型、Logistic 回归与 LDA：从概率建模到分类决策

适用形式：约 10 分钟知识汇报。正文可直接讲述；末尾补充说明用于准备追问，不计入正文时间。文中数字均为解释概念的假设例子。公式使用普通文字写法。

## 汇报正文

### 一、从线性评分说起

大家好，今天我汇报的主题是线性模型、Logistic 回归与 LDA。重点是说明它们怎样产生概率，以及我们应该怎样评价和使用这些概率。

以疾病分类为例，输入是年龄、检查指标等特征，输出是是否患病。这里需要区分三个层次：模型先计算评分，再给出概率，最后根据阈值决定类别。

线性评分，就是“截距加上各项特征与对应权重的乘积”。在两个特征的图上，评分等于某个固定值时，对应一条直线，这就是线性边界。三个特征时是平面，更多特征时是超平面。这个名称描述的是边界形状，数据点可以散布在各处。

### 二、Logistic 回归：直接学习条件概率

Logistic 回归直接建模“给定这些特征，一个人患病的概率”。它先计算线性评分 z，再通过 sigmoid，把任意实数转换到 0 到 1 之间。评分为 0 时，概率为 50%；评分越大，概率越接近 1。

要理解它的系数，还需要区分 probability、odds 和 logit。概率是患病人数占总人数的比例；odds 是患病人数与未患病人数之比。例如患病概率为 20%，odds 就是 0.2 除以 0.8，等于 0.25。logit 则是对 odds 取自然对数。Logistic 的线性假设，指的是 logit 与输入特征线性，而不是概率本身与输入线性。

训练时，模型估计截距和权重，让真实阳性获得较高的患病概率，真实阴性获得较低的患病概率。无惩罚情况下，这相当于最大化条件似然，或者最小化二分类交叉熵。交叉熵会特别惩罚“非常自信却预测错误”的情况。L2 正则化进一步惩罚过大的系数，可以改善部分小样本和共线性问题，但也会使系数向零收缩。在常见实现中，C 越小，正则化越强。

系数还可以转换为 OR，也就是 odds ratio。其他变量固定时，一个特征增加一个建模单位，odds 乘以 exp(β)。例如 OR 为 2，表示 odds 翻倍。原概率如果是 20%，odds 从 0.25 翻到 0.5，新概率约为 33.3%，并不是 40%。因此，OR 不能直接当作概率倍数。解释 OR 时，必须说明变量单位、分类参照，以及其他变量固定；标准化后的一个单位通常是一个标准差。

### 三、LDA：先学习各类分布，再计算后验概率

LDA 是线性判别分析。它先分别学习患病组和未患病组的特征分布，再判断新样本更符合哪一组。这是一条生成式建模路线。

LDA 主要估计三类参数：各类均值、共享协方差和类别先验。均值表示每类的中心；协方差描述特征的波动与共同变化；先验表示查看个人指标前的类别概率。它假设各类特征近似服从多元正态分布，并共享同一个协方差矩阵。共享协方差允许变量相关，不要求两类均值相同。

得到概率时，LDA 先计算“类条件密度乘以先验”，再除以各类这些数值的总和，得到相加为 1 的后验概率。密度表示某类中指标组合的常见程度，本身不是患病概率。

为什么这种方法也有线性边界？因为比较两类的高斯对数密度时，共享协方差使共同的二次项抵消，留下线性项。二分类 LDA 的概率也能写成 sigmoid 加线性评分，但其评分来自均值、协方差和先验，与 Logistic 直接拟合条件概率的来源不同。若各类使用不同协方差，通常得到二次边界，这就是 QDA。

### 四、编码和参数量怎样影响选择

比较模型前，要先看编码后的维度。一个四分类变量采用参考编码时，需要三列；全为零就表示参考类别。因此原始变量数量不等于输入列数。

假设编码后有 q 个非冗余特征，二分类 Logistic 估计 q 个系数和一个截距。常规 LDA 估计两组均值、一个共享协方差和一个独立先验。例如 q 为 20 时，Logistic 有 21 个参数，LDA 的常规计数是 251 个。LDA 的协方差参数随维度大致平方增长，需要关注小样本下的估计稳定性。但参数量不能单独决定优劣，还要结合假设、正则化和验证证据。

### 五、评价模型需要区分排序、概率和行动

模型评价至少有三个层次。第一是排序，ROC-AUC 衡量阳性是否通常排在阴性前面；PR 曲线则观察 precision 与 recall 的权衡，尤其便于理解阳性较少时的检出与误报负担。AP 是汇总 PR 表现的一种方法，与梯形积分的 PR-AUC 不完全相同。

第二是概率质量。Brier score 计算预测概率与真实标签的平均平方误差；log loss 对高置信度错误更敏感，两者通常越小越好。校准则问：被预测为约 70% 的一群人中，是否确实约有 70% 为阳性。Brier 和 log loss 是综合概率评分，不能当作纯校准指标。

第三是指定阈值下的行动错误。Sensitivity 看真正患者中检出多少；specificity 看未患病者中正确排除多少；precision 看预测阳性中真正患病的比例。它们的分母不同。AUC 高不保证概率准确，也不保证某个阈值的漏诊和误报合适。

### 六、阈值必须连接错误代价

预测概率还需要通过阈值转成类别。降低阈值，会让更多人被判为阳性，通常减少漏诊、增加误报；原始概率和模型参数没有改变。

假设漏诊代价是误报的五倍，就可以比较“5×FN＋FP”。从漏诊两人、误报十六人，变成漏诊一人、误报二十八人，虽然少漏一人，总成本却从 26 增加到 33。所以阈值不能只追求更高的检出率，也不能机械采用 0.5。阈值应在开发数据中依据任务代价选择，并在最终测试前固定。

### 七、可信评价还需要无泄漏验证与稳定性检查

验证时，填补、标准化、编码、特征选择和模型拟合，都应只使用当前训练折。验证折只接受已经拟合好的转换。在全部数据上先标准化再交叉验证，仍然借用了验证信息。Pipeline 可以帮助执行这个边界。

模型和阈值在开发数据中选择，冻结后再评价独立测试集。如果看完测试结果继续调整，测试集就参与了选择。同一患者有多条记录时，还应考虑按患者分组划分。

此外，小样本指标需要表达不确定性。Bootstrap 通过有放回重抽样观察统计量波动。评价固定模型的测试指标时，抽取标签与预测的配对记录；研究系数稳定性时，则重抽开发数据并重新拟合完整流程。

预测稳定也不等于系数稳定。两个高度相关的指标，可能在不同抽样中重新分配正负系数，但组合后的评分变化很小。因此预测表现、系数分布和 OR 区间要分别检查。对 LDA 的分布与协方差假设、Logistic 的 logit 形式，也应结合预测、校准和稳定性证据判断，不能靠一次假设检验机械决定。

### 八、方法选择与结论边界

方法选择应连接研究目标、样本量、编码维度、模型假设、概率质量和错误代价。患病比例基线用于检查模型是否超越“不看个人特征”；Gaussian NB 则提供一个类内条件独立的生成式参照。

最后，系数和 OR 表示模型中的条件关联，不能自动解释为因果效应。内部测试也不足以证明跨医院泛化或临床获益。报告中应让主张、证据、推理和适用边界相互对应。我的汇报到这里，谢谢大家。

## 补充讲解备忘

以下内容用于准备追问，可根据现场时间展开。

### 1. Logistic 的三个转换分别做什么

- sigmoid：把线性评分转换成预测概率，p＝1／(1＋exp(−z))。
- odds：比较发生与不发生的可能性，odds＝p／(1−p)。
- logit：把 odds 取自然对数，logit(p)＝ln[p／(1−p)]。
- Logistic 设定 logit(p)＝线性评分。sigmoid 和 logit 是反方向的转换，预测时通常是“输入→评分→sigmoid→概率”。
- 截距对应输入取编码零点时的评分；其 sigmoid 是该基准条件下的预测概率，不必等于总体患病比例。
- 阈值 t 对应评分门槛 ln[t／(1−t)]。例如 t＝0.5 对应 0；t＝0.2 对应约 −1.386。单独改阈值是在改变行动门槛。
- 普通线性回归主要建模连续结局的条件均值，预测可超出 0 到 1；不能直接把普通线性回归输出当作合法概率。

### 2. 似然、交叉熵与正则化

真实阳性对应的概率是 p，真实阴性对应的概率是 1−p。在常规独立观测假设下，把每个人真实结果对应的概率相乘，得到条件似然。取负对数，把连乘转换成求和，就得到交叉熵。无惩罚情况下，最大化条件似然与最小化交叉熵等价。

正则化目标可以理解为“预测损失＋系数惩罚”。L2 使用系数平方和作惩罚基础，通常不会直接删除输入列，但会约束有效复杂度。惩罚太强也可能损失有用信号。完全分离时，无惩罚模型可通过不断增大系数，让正确类别的概率持续接近 1，因此有限最优系数可能不存在；正则化可帮助约束这一问题。

### 3. 一个完整的 LDA 概率例子

假设先验患病概率为 0.4，未患病概率为 0.6。某人的指标在患病组密度为 0.3，在未患病组密度为 0.1。

患病这一边：0.4×0.3＝0.12；未患病这一边：0.6×0.1＝0.06。归一化后，患病概率＝0.12／(0.12＋0.06)≈66.7%。密度表示连续指标在某类分布中的常见程度；连续区间下的面积才是概率，密度数值本身不必在 0 到 1 之间。

一维情况下，若未患病组均值为 0，患病组均值为 2，共同方差为 1，先验各半，比较对数密度时出现“−x²／2”和“−(x−2)²／2”。后一项展开为“−x²／2＋2x−2”。共同的平方项抵消，分数差为 2x−2，所以边界为 x＝1。经过 sigmoid，x 为 0、1、2 时，患病概率分别约为 11.9%、50%、88.1%。

多变量下，LDA 的分数方向由“共享协方差的逆×两类均值差”确定。因此它不仅比较中心距离，也考虑尺度和相关结构。冗余输入可能使协方差奇异，需要降维、SVD 或协方差收缩等处理。

常规 LDA 的估计对应类条件高斯与类别先验的联合似然。各类均值、共享协方差和先验常用带标签训练数据的样本统计量估计；具体协方差缩放与求解方式依实现而异。它与 Logistic 直接优化条件交叉熵的估计路线不同。

### 4. 参数量、参考编码和 OR

| 模型 | 常规二分类计数，q 为非冗余输入维度 | q＝20 时 |
|---|---|---:|
| Logistic | q 个系数＋1 个截距 | 21 |
| LDA | 2q 个均值＋q(q＋1)／2 个共享协方差参数＋1 个独立先验 | 251 |
| QDA | 2q 个均值＋q(q＋1) 个协方差参数＋1 个独立先验 | 461 |

协方差计数包含 q 个方差，以及 q(q−1)／2 个不同变量对的协方差；矩阵对称，所以不重复计数。两类先验相加为 1，只有一个独立参数；若先验固定给定，不计入需要估计的参数。

K 类变量采用参考编码时使用 K−1 列。参考类别的所有指示列都为零，信息仍被保留。全水平 one-hot 同组各列之和恒为 1，与截距存在冗余，因此按列数得到的参数条目不能直接解释成独立可辨识参数数。

参考编码中，某类别相对参考类的 OR＝exp(该类别系数)。全水平编码中，从 A 切换到 B，是 A 指示列由 1 变 0、B 由 0 变 1，因此 OR＝exp(B 系数−A 系数)。连续变量增加 Δ 个建模单位，对应 OR＝exp(β×Δ)。系数大小依赖单位、标准化、参照与调整变量，不能直接等同于重要性。

### 5. 四种比较对象的区别

| 对象 | 主要作用或假设 |
|---|---|
| 患病比例基线 | 对每人给出训练阳性比例，检查是否获得个人层面的增益 |
| Gaussian NB | 类内各特征分别高斯，给定类别后条件独立；各类方差可以不同 |
| LDA | 类条件联合高斯，共享完整协方差，允许特征相关 |
| Logistic | 直接建模条件概率，无需完整指定类条件输入分布 |

Gaussian NB 的独立性发生在类别内部；同组 one-hot 列存在约束，通常不符合条件独立。二元列也不严格连续高斯。混合变量会给生成式高斯假设带来压力，需要观察实际预测后果。

### 6. 评价指标及阈值成本

| 指标 | 普通文字计算或解释 |
|---|---|
| Sensitivity／recall | TP／(TP＋FN)，真正阳性中检出多少 |
| Specificity | TN／(TN＋FP)，真正阴性中排除多少 |
| Precision／PPV | TP／(TP＋FP)，预测阳性中真正阳性多少 |
| Accuracy | (TP＋TN)／总人数 |
| FPR | FP／(FP＋TN)，等于 1−specificity |
| ROC-AUC | 随机阳性比随机阴性评分更高的概率，同分计一半 |
| AP | 汇总 PR 表现的一种评分，受阳性比例影响 |
| Brier | 概率与真实标签之差的平方，再对所有人取平均 |
| Log loss | 对真实结果赋予低概率时惩罚增大，尤其惩罚高置信度错误 |

Precision 会受到患病比例影响，不能把不同人群的 PPV 直接视为相同。把所有概率作严格单调变换，可以保留排序和 AUC，却改变概率质量及同一数值阈值的分类结果。

只有误报与漏诊有代价、正确分类代价为零，并且 p 是目标人群中的校准风险时，判阳性的期望成本为 C_FP×(1−p)，判阴性的期望成本为 C_FN×p。两者比较得到理论阈值 C_FP／(C_FN＋C_FP)。漏诊代价为误报五倍时，阈值为 1／6。经验概率失准或样本有限时，不能直接把该数值当作验证得到的最优阈值。

改变类别比例、重采样或带权训练后，需要重新检查输出概率是否适用于目标人群。重新训练带权模型会改变拟合过程，不能等同于单独改变分类阈值。

### 7. 验证、Bootstrap 与解释边界

开发数据用于模型、超参数和阈值选择；交叉验证每轮在训练折拟合完整流程，得到验证折预测。OOF 概率意味着每人的预测来自没有使用此人训练的模型。反复开发选择仍可能乐观，必要时使用嵌套交叉验证；最终测试集只在完整方案固定后评价。拟合概率校准器也必须遵守训练和评价分离。

测试指标 bootstrap 应成对抽取每人的标签和预测。比较模型时，对相同重抽样索引计算指标差值。可用重抽样分布的两端分位数构成近似区间，不能只看点估计或两个区间是否重叠。AUC 要求抽到的评价样本包含两类；重复测量、聚集数据需选择适当的患者或群组抽样单位。

系数 bootstrap 应重拟合预处理与模型，并对齐特征、参照和单位。每轮标准化的标准差可能变化，可换回共同原单位比较。带惩罚模型的区间应结合该估计流程解释。预测稳定与单个系数稳定是两种证据。

假设诊断应检查类内分布、偏态、离群点、协方差差异、冗余和估计稳定性；单个变量近似正态不能充分证明联合正态，一次显著性检验也不能单独裁决模型是否有用。Logistic 同样需要审查 logit 形式、分离和共线性。探索性压力测试应在开发数据中完成。

观察性模型的 OR 不自动是因果效应；一个 OR 最大也不代表该变量是最重要的致病因素。结局定义决定解释范围：识别当前疾病存在，不能自动改称预测未来若干年的发病。内部评价不能替代跨医院、跨时间等外部验证，以及真实临床获益证据。表达结论时，可采用“主张—证据—推理—边界”的结构。
