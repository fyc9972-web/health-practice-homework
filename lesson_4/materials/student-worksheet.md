# Chapter 5 学生工作单：统计检验与假设设计

## 数据情境

你是一名研究助理。团队想知道心脏病证据是否与最大运动心率有关，并准备把“有关”写成研究结论。请先读 `data/README.md`。

## 任务 1：把问题变成假设

填写：研究对象；比较对象；主要终点；分析单位；H0；H1；α；双侧还是单侧及理由。

* 研究对象：四个中心数据库中的920名受试者
* 比较对象：`disease=1` 与 `disease=0` 两个独立组
* 主要终点：最大运动心率 `thalach`，连续变量。
* 分组变量：`disease`，二分类变量。
* 分析单位：每名受试者。
* 数据性质：观察性横断面资料，不是随机试验。
* 主要分析：有完整 `disease` 和 `thalach` 数据的受试者
* H0：无关 没有差异（两组总体平均最大运动心率没有差异）
* H1：有关（两组总体平均最大运动心率存在差异）
* α：0.05
* 检验方向：双侧，题目只问“是否不同”，所以应该使用双侧检验。无论疾病组高还是低，只要差异足够明显，都可能拒绝H0

## 任务 2：错误类型与 power

各写一个 Type I 和 Type II error。说明样本量、真实效应和测量噪声如何影响 power，并解释未拒绝 H0 的边界。

- Type I error：实际上两组总体平均 `thalach` 没有差异，但研究错误地得出“存在差异”的结论，也就是假阳性。
- Type II error：实际上两组总体平均 `thalach` 存在差异，但研究未能发现，错误地认为证据不足，也就是假阴性。
- Power 是“真实差异存在时，检验成功发现它的概率”。
- 当前数据没有提供足够证据拒绝H0，但这不等于证明H0正确，也不等于证明两组完全相同。

## 任务 3：选择方法

为下列问题写出首选方法、一个关键假设和一个备选方法：

1. 疾病组与无疾病组的 `thalach` 是否不同？
2. 同一患者前后测量是否变化？
3. `sex` 与 `disease` 的比例是否有关？
4. `age` 与 `thalach` 是否相关？
5. `age`、`sex`、`thalach` 能否预测 `disease`？


| 问题                                     | 首选方法           |                                                               | 备选方法                                          |
| ---------------------------------------- | ------------------ | ------------------------------------------------------------- | ------------------------------------------------- |
| 两独立疾病组的`thalach`是否不同          | Welch独立样本t检验 | 个体之间独立；数据近似正态或样本足够大                        | 均值置换检验；若研究秩或分布，可用Mann–Whitney U |
| 同一患者前后测量是否变化                 | 配对t检验          | 配对差值近似正态，并且配对关系正确                            | Wilcoxon符号秩检验                                |
| `sex`与`disease`是否有关                 | 卡方独立性检验     | 观察相互独立，期望频数足够大                                  | Fisher精确检验                                    |
| `age`与`thalach`是否相关                 | Pearson相关        | 关系近似线性，无严重异常值                                    | Spearman秩相关                                    |
| `age`、`sex`、`thalach`能否预测`disease` | 多变量二元逻辑回归 | 结局为二分类，观察独立，连续变量与logit关系合理，无严重共线性 | 惩罚逻辑回归                                      |

## 任务 4：报告一个主要结果

预先指定 `thalach` 为主要终点。报告每组 n、描述统计、效应量、95% CI、p-value、H0 决策，并分别说明统计关联、实际意义和因果边界。

- 在具有完整 `thalach` 数据的865名受试者中，`disease=1` 组474人的最大运动心率均值为128.26次/分钟（SD=24.02），`disease=0` 组391人的均值为148.80次/分钟（SD=23.61）。Welch独立样本t检验显示，疾病组的平均最大运动心率比无疾病组低20.54次/分钟，95% CI为17.35至23.73次/分钟，\\(t(837.18)=-12.63\\)，\\(p<0.001\\)，因此在α=0.05水平拒绝H0。标准化效应Hedges’ \\(g=-0.86\\)，提示样本中的标准化差异较明显，但其临床重要性仍需根据预先规定的临床意义阈值判断。该结果只支持统计关联，不能证明心脏病导致最大运动心率降低。

## 任务 5：风险与退出卡

指出至少两个混杂因素，说明控制或敏感性分析；解释 20 个指标中只挑显著一个的风险。最后用“主张—证据—推理—边界”写四句话。

混杂因素：

* 年龄：年龄可能同时与疾病状态和最大运动心率有关。
* 性别：男女的疾病比例和运动心率可能不同。
* `site`：各中心的人群构成、测量方式和转诊来源可能不同。
* 控制计划：使用多变量线性回归，以 `thalach` 为结局，将 `disease`、`age`、`sex` 和 `site` 同时纳入模型，估计校正后的疾病组差异。进一步进行按中心分层分析，检查不同中心结果是否一致

#### 主张—证据—推理—边界”四句话范例

1. 主张：在本样本中，有心脏病证据的受试者具有较低的最大运动心率。
2. 证据：疾病组均值为128.26次/分钟，无疾病组为148.80次/分钟，平均差为−20.54次/分钟，95% CI为−23.73至−17.35，\\(p<0.001\\)。
3. 推理：置信区间不包含0，且双侧Welch t检验达到预设α=0.05，因此拒绝两组总体均值相等的H0。
4. 边界：该结果来自观察性资料，可能受到年龄、性别、中心和缺失值等因素影响，只能支持关联，不能证明因果
