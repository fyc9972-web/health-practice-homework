# 第 3 课课堂重点：高维数据与降维

依据本课工作单、实验说明和已有核心问题答案整理。

1. 高维数据常表现为特征数远大于独立样本数；本课是 120 位患者、23,146 个基因。
2. 特征更多不一定预测更好；无关维度、距离变化及过拟合都会影响解释。
3. 训练表现不能代替未见样本表现；划分应按患者进行，拟合步骤只使用允许的开发数据。
4. 标准化会改变变量在距离或方差中的权重，应由测量尺度和分析目的决定。
5. PCA 寻找解释方差较大的线性方向；主成分是变量的线性组合，不自动等于疾病机制。
6. UMAP 更关注局部邻域结构，图上簇与距离会受参数及随机性影响；二维图不能自行证明新亚型。
7. 可视化用于探索，模型评价和生物学解释需要各自的证据。
