## 第 3 讲a：高维数据与维度灾难 （zhang)

**主题** 为什么生物医学数据经常“变量很多，样本很少”？

**核心问题**

· 什么是高维数据？

· 为什么高维会带来统计和机器学习困难？

· 什么是维度灾难？

**主要内容**

· 高维数据例子：

o 转录组：几万个基因

o 蛋白组：几千个蛋白

o 代谢组：数百到数千个代谢物

o 医学影像：大量像素或深度特征

o 单细胞数据：细胞数多、基因数多、噪声大

· 维度灾难：

o 样本之间距离变得不可靠

o 模型容易记住训练数据

o 统计检验数量急剧增加

o 可视化困难

o 噪声特征可能掩盖真实信号

· “大 p 小 n”问题：

o p = 特征数

o n = 样本数

o 生物医学研究中常见 p >> n

**课堂练习** 用二维、三维和高维模拟数据展示：

· 距离分布如何随维度变化

· 高维下最近邻和最远邻差异变小

· 为什么高维数据更容易过拟合

**作业** 用自己的话解释：为什么“特征越多”不一定意味着“模型越好”？

## 第 3 讲b：降维、PCA 与 UMAP (zhang)

**主题** 如何把复杂高维数据压缩到可理解的低维空间？

**核心问题**

· 降维是为了可视化，还是为了建模？

· PCA 和 UMAP 有什么区别？

· 如何避免过度解释降维图？

**主要内容**

· 降维目的：

o 可视化

o 去噪

o 压缩特征

o 发现样本结构

o 作为后续建模输入

· PCA：

o 线性降维

o 最大化方差解释

o 主成分

o explained variance

o loading 的含义

· UMAP：

o 非线性降维

o 更适合展示局部结构

o 常用于单细胞和复杂表型数据

· PCA vs UMAP：

o PCA 更容易解释

o UMAP 更适合可视化复杂结构

o UMAP 图中的距离和簇不能过度解释

· 常见错误：

o 把 UMAP 上的簇直接当作生物学真相

o 在全数据上先降维再交叉验证，导致信息泄露

o 不做标准化就直接 PCA

**课堂练习** 用一个 gene expression 或 clinical-feature 数据集：

· 标准化数据

· 做 PCA

· 画 PC1 vs PC2

· 做 UMAP

· 比较两种图的差异

**作业**解释：

· PCA 第一主成分代表什么？

· 为什么 PCA 前通常需要标准化？

· UMAP 图能说明什么，不能说明什么？
